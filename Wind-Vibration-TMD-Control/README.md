# Wind-Induced Vibration Control using TMD

## Project Overview
This project investigates the dynamic response of a 200m tall building under stochastic wind loads.

## Tasks Performed
*   Simulated the fluctuating wind velocity using the Davenport Spectrum and IFFT.
*   Applied Modal Analysis to extract natural frequencies (f1 = 0.062 Hz).
*   Designed a passive Tuned Mass Damper (TMD) to reduce peak acceleration from 22 milli-g to 11 milli-g.
*   Utilized Fast Fourier Transform (FFT) in MATLAB to analyze the acceleration spectrum.
